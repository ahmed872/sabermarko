مولّد أكواد التفعيل

سابر ماركو — يعمل بدون إنترنت على جهازك فقط. لا يُرسل أي شيء لأي مكان.

اختر الملف الذي حفظته عند إنشاء المفتاح.
يظهر للعميل في شاشة «الترخيص» داخل البرنامج، ويرسله لك.
كود التفعيل — أرسله للعميل كما هو:

تفعله مرة واحدة فقط في حياة البرنامج. المفتاح الخاص هو «ختم» أكواد التفعيل: من يملكه يستطيع تفعيل أي نسخة.

إذا أنشأت مفتاحًا جديدًا بعد نشر البرنامج، فكل أكواد التفعيل القديمة لن تعمل مع النسخة الجديدة. لا تضغط هذا الزر مرة ثانية إلا إذا كنت تقصد ذلك.

✅ تم. نزل ملف sabermarko-private-key.pem في مجلد التنزيلات.

  1. اضغط «نسخ المفتاح الخاص» بالأسفل.
  2. في GitHub افتح المستودع ← Settings ← Secrets and variables ← Actions ← New repository secret.
  3. الاسم: SBM_LICENSE_PRIVATE_KEY — والقيمة: الصق المفتاح ← Add secret.
  4. احتفظ بالملف على فلاشة كنسخة احتياطية. لا ترسله لأحد ولا تضعه داخل ملفات المشروع.

بعدها: كل إصدار من GitHub يُبنى بهذا المفتاح تلقائيًا، وتولّد أكواد التفعيل من Actions ← «توليد كود تفعيل» (حتى من الموبايل) أو من هذه الصفحة.
