# دليل الاستخدام السريع

## أول تشغيل
1. شاشة الترحيب ← اسم المحل والهاتف والعنوان والشعار (اختياري؛ بدون شعار تُنشأ أيقونة من الحروف الأولى).
2. العملة ونوع الطابعة (حراري 80 مم هو الأشيع) وطريقة العمل: **بسيط** أو **متقدم**.
3. حساب المدير (اسم دخول + كلمة مرور).
4. تبدأ فترة تجريبية 20 يومًا. البرنامج يعمل بالكامل بدون إنترنت.

**جهاز جديد ومعك نسخة احتياطية من المحل القديم؟** من أول شاشة اختر «عندي نسخة احتياطية من البرنامج — استعادة بيانات محلي» واختر الملف من الفلاشة؛ تعود كل بياناتك (المنتجات والفواتير والمستخدمين وكلمات المرور).

المحل يبدأ نظيفًا بدون أي بيانات وهمية. أول خطوة: **المنتجات ← منتج جديد** (يكفي الاسم والسعر) أو **استيراد من Excel**.

## البيع (شاشة الكاشير)
| الاختصار | الوظيفة |
|---|---|
| F1 | بيع جديد / مسح الفاتورة |
| F2 | الذهاب لخانة البحث |
| F3 | تعديل كمية الصنف المحدد |
| F4 | خصم على الصنف |
| F5 | اختيار عميل |
| F6 | تعليق الفاتورة |
| F7 | الفواتير المعلقة |
| F8 | خصم على الفاتورة |
| F9 أو Enter في خانة بحث فارغة | الدفع |
| + / − | زيادة/نقص الكمية |
| Del | حذف الصنف |
| ↑ / ↓ | التنقل بين الأصناف |
| Esc | إلغاء الفاتورة |

- **بدون قارئ باركود:** ابحث بالاسم أو الكود، أو اختر من التصنيفات و"المنتجات السريعة".
- **بقارئ باركود:** امسح مباشرة — البرنامج يلتقط الكود حتى لو لم تكن خانة البحث محددة.
- **المنتجات بالوزن:** اضغط المنتج واكتب الوزن بالجرام أو الكيلو، أو بالمبلغ ("جبنة بـ 50 جنيه"). الفاتورة تُظهر: `250 جم × 180 / كجم = 45`.
- **الأحجام** (كوكاكولا 330 مل / 1 لتر…) تظهر كبطاقة واحدة ثم تختار الحجم.
- **الكرتونة:** اضغط مرتين على الصنف لتغيير الوحدة (قطعة/كرتونة).
- **الدفع:** نقدي (مع حساب الباقي وأزرار الفكة السريعة)، كارت، محفظة، آجل (لعميل)، أو تقسيم المبلغ بين أكثر من طريقة.
- الخصم الأكبر من حد الكاشير، وتعديل السعر، والبيع الآجل تحتاج **موافقة مدير**: يكتب المدير اسمه وكلمة مروره على نفس الشاشة وتُسجل الموافقة في سجل العمليات.

## الوردية والخزنة
افتح الوردية بالرصيد الموجود في الدرج. أثناء الوردية: سحب/إضافة نقدية بسبب. عند الإغلاق اكتب النقدية الفعلية: يظهر **المتوقع** و**الفعلي** و**الفرق** ويُطبع تقرير الوردية.

## المرتجع والإلغاء
- **مرتجع:** المبيعات ← افتح الفاتورة (أو اكتب رقمها) ← مرتجع ← حدد الكمية. اختر "سليم" ليرجع للمخزون أو "تالف".
- **إلغاء فاتورة:** متاح لفواتير اليوم فقط، بسبب مكتوب، ويحتاج صلاحية أو موافقة مدير.

## المشتريات والموردون
**المشتريات ← شراء جديد:** المورد، رقم فاتورته، الأصناف بالكرتونة أو القطعة، سعر الشراء، المدفوع. المتبقي يُضاف لحساب المورد تلقائيًا، والمخزون يزيد، والتكلفة تتحدث (متوسط مرجح). يمكن تحديث سعر البيع من نفس الفاتورة.

## المخزون والجرد
- كل تغيير في المخزون له سبب ويظهر في **سجل حركة المنتج** (قبل/بعد/من/متى).
- **تلف / فقد / تسوية** من صفحة المخزون.
- **الجرد:** ابدأ جردًا (كامل أو لتصنيف)، اكتب الكمية الفعلية، راجع الفروق وقيمتها، ثم "اعتماد الجرد".
- **النواقص واقتراحات الطلب:** الكمية المقترحة بالكرتونة حسب سرعة البيع ومدة توريد المورد — البرنامج يقترح ولا يطلب تلقائيًا.

## اقتراحات البيع (العروض الذكية)
تصنف المنتجات تلقائيًا: 🔥 عليه سحب • 🟢 مستقر • 🟡 حركته ضعيفة • 🔴 راكد • ⚠️ مخزون زائد • ⏳ معرض للانتهاء.
كل عرض مقترح يوضح **لماذا** و**الربح قبل/مع العرض**، ولا يُعرض عرض يسبب خسارة كأنه جيد. أنت تعتمد أو تعدل أو ترفض أو تطلب عدم الاقتراح لمنتج/نوع. بعد العرض تظهر **نتيجته** (الكمية، الربح، الهامش، انخفاض المخزون).

## إغلاق اليوم والتقارير
**إغلاق اليوم:** صافي المبيعات، المرتجعات، الخصومات، تكلفة البضاعة، مجمل الربح، المصروفات، صافي الربح، المقبوض بكل طريقة، فرق الخزنة — ويُعمل نسخة احتياطية تلقائيًا.

## النسخ الاحتياطي
- أعلى صفحة **النسخ الاحتياطي**: تاريخ آخر نسخة وحجمها و«الحالة: سليمة وتم التحقق منها». كل نسخة تُفحص فور إنشائها.
- تلقائي في الخلفية + عند إغلاق اليوم. إذا مر 7 أيام بدون نسخة يظهر تنبيه في الرئيسية.
- أزرار: **إنشاء نسخة الآن**، **استعادة نسخة**، **حفظ نسخة على فلاشة**، **فتح مجلد النسخ**.
- الاستعادة: اختر النسخة ← يفحصها البرنامج ويعرض اسم المحل وتاريخها ومحتواها ← تأكيد ← يحفظ نسخة «قبل استعادة» من بياناتك الحالية في مجلد النسخ (للتراجع إذا اخترت نسخة خطأ) ← استعادة ← فحص.
- الملف التالف أو من إصدار أحدث من البرنامج يُرفض برسالة واضحة ولا تُمس بياناتك. النسخ من إصدار أقدم تُرقّى تلقائيًا.
- إذا تلفت قاعدة البيانات (انقطاع كهرباء/عطل قرص) يفتح البرنامج شاشة **استعادة البيانات** تلقائيًا.
- احفظ نسخة على فلاشة أو خارج الجهاز أسبوعيًا على الأقل.

## المستخدمون
- عدد المستخدمين **النشطين** محدود حسب الترخيص (يظهر «المستخدمون النشطون: 3 من 5»). عند الوصول للحد أوقف مستخدمًا لم يعد يعمل (لا يُحذف وتبقى فواتيره) أو قم بترقية الترخيص.
- كل مستخدم يغيّر كلمة مروره من زر القفل أسفل القائمة الجانبية.

## التفعيل
**الترخيص:** انسخ "كود الجهاز" وأرسله للشركة، ثم الصق كود التفعيل. لا يحتاج إنترنت.
